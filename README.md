# Lemon 28

Website for Lemon 28, the fresh-shaken lemonade pop-up in Kissimmee, FL.

- `index.html` is the finished site (one self-contained file, every picture is built in). Open it or host it as is.
- `assets/` holds the pictures the page uses (drink cups, lemons, logo, Zelle QR code).
- To change something, edit `index.src.html`, then run `python3 build.py` to rebuild `index.html`.
- The pop-up dates live in the `SCHEDULE` list and the prices in `PRICES`, both near the bottom of `index.src.html`.
